# 快速教程（1.0.2）

1.0.2 的教程与 1.0.0 完全一致，修复了 HDRI 天空盒无效与白闪问题。完整教程见 [1.0.0 教程](../1.0.0/Tutorial.md)。

## HDRI 天空盒（本版本修复点）

1. 打开任意 Scenecaps 资产编辑器，视口顶部工具条有 `HDRI Skybox` 复选框与 `Select HDRI...` 按钮。
2. 点击 `Select HDRI...` 选择一个 `TextureCube` —— 1.0.2 起视口会显示完整的 HDRI 天空球背景（此前版本只产生小范围 IBL 效果）。
3. 移动视角不应再出现白色/正常闪烁。
4. 取消复选框即关闭天空盒，视口恢复原来的深色背景。
