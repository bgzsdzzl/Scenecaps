# 使用说明（1.0.2）

1.0.2 的使用说明与 1.0.0 完全一致，唯一变化是 HDRI 天空盒现已正确显示为可见背景且不再闪烁。完整说明见 [1.0.0 使用文档](../1.0.0/Usage.md)。

## 本版本修复点

- **HDRI 可见背景**：现在选择 HDRI 后，视口通过反法线球 + `bIsSky` 材质显示完整天空盒背景，不再只是小范围的颜色效果。
- **白闪消除**：视口改用 `DisableAdvancedFeatures()` 关闭 TAA / ScreenPercentage / 自动曝光等高级特性，移动视角时不再在白色与正常之间闪烁。
- **IBL 独立**：可见天空与 SkyLight 环境照明相互独立，捕获内容持续刷新，避免帧间状态不稳定。

## 其余功能

场景集合与条目、变体与过渡、修改器、程序化生成、ISM/HISM、Data Layer、快照、Actor 池、`.scx` / `.scnb` 导入导出、资产拖入关卡等用法均未变化，详见 [1.0.0 使用文档](../1.0.0/Usage.md)。
