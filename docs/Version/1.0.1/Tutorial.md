# 快速教程（1.0.1）

1.0.1 的教程与 1.0.0 完全一致，仅修复了「把资产拖入关卡」这一步。完整教程见 [1.0.0 教程](../1.0.0/Tutorial.md)。

## 关键步骤：把集合拖入关卡

1. 在内容浏览器中选中 **Scene Collection** 资产（如 `SC_Forest`）。
2. 直接拖入关卡视口 —— 1.0.1 起会生成 `AScenecapsActor` 容器，并自动设置 `CollectionAsset` 与重建预览（此前的版本拖放无效；也可右键资产 → **Place into Level**）。
3. 选中容器，在 Details 中切换 `ActiveVariant` 即可看到效果。

## 其余步骤

创建资产、添加条目、变体覆盖、变体过渡、批量实例化、HDRI 天空盒等流程均与 [1.0.0 教程](../1.0.0/Tutorial.md) 相同。
