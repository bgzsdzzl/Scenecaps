# 生成性 AI 使用方针

本文档规定 Scenecaps 项目中使用生成性 AI 工具（GitHub Copilot、ChatGPT、Claude 等）的规范。

---

## 核心原则

1. **人类主导** - AI 仅作辅助，决策与责任由人类承担
2. **可追溯** - AI 生成代码必须标记、可审查、可追溯
3. **可验证** - AI 生成内容必须可编译、可测试、可运行
4. **合规** - 遵守许可证、版权、隐私与安全要求

---

## 允许使用场景

| 场景 | 说明 |
|------|------|
| 样板代码生成 | Boilerplate、重复模式、UE 宏/反射代码 |
| 算法/数学实现 | 明确逻辑的数学/几何/算法实现 |
| 文档/注释生成 | API 文档、代码注释、CHANGELOG 起草 |
| 重构辅助 | 重命名、提取函数、移动代码 |
| 测试用例生成 | 基于现有模式的测试桩代码 |
| 语法/API 查询 | UE API 用法、编译错误修复建议 |
| 重构建议 | 代码异味识别、重构方向建议 |

---

## 禁止使用场景

| 场景 | 原因 |
|------|------|
| 核心架构决策 | 需人类架构师把控整体设计 |
| 安全/加密/认证代码 | 涉及安全边界，需人工审核 |
| 含商业机密/私有数据 | 避免数据泄露 |
| 许可证不兼容代码 | 避免 GPL 等传染性许可证污染 |
| 直接提交未审查代码 | 所有 AI 代码必须人工审查后提交 |
| 绕过代码审核 | PR 必须经过人工审核流程 |

---

## 标记规范

AI 生成或辅助的代码提交时需在 commit message 或 PR 中标记：

```
feat: add biome radial distribution

AI-assisted: Copilot generated radial distribution algorithm
Reviewed-by: @reviewer
```

或在 PR 描述中声明：
```
AI-assisted: Yes
Tool: GitHub Copilot / ChatGPT-4
Reviewed-by: @reviewer
```

---

## 审核要求

所有 AI 生成代码必须经人工审核，重点检查：

- [ ] 逻辑正确性（边界条件、异常处理）
- [ ] UE 编码规范合规
- [ ] 内存安全（GC、智能指针正确使用）
- [ ] 性能无退化（无不必要的分配/拷贝）
- [ ] 无硬编码/魔法数字
- [ ] 错误处理完整
- [ ] 单元测试/手动测试通过
- [ ] 许可证兼容（无 GPL 等传染性代码）

---

## 工具配置建议

### GitHub Copilot
- 启用「建议公共代码」过滤
- 关闭「允许使用与公共代码匹配的建议」
- 启用「阻止建议包含敏感信息」

### ChatGPT / Claude
- 不输入商业机密、密钥、私有代码库完整内容
- 使用「不训练模型」模式（如可用）
- 仅查询公开 API/算法/通用模式

---

## 版权与许可

- AI 生成代码视为贡献者创作，遵循项目 Apache 2.0 许可
- 若 AI 输出包含受版权保护代码片段，必须移除或重写
- 不得将专有代码输入 AI 工具（除本地离线模型）

---

## 违规处理

| 违规类型 | 处理 |
|----------|------|
| 未标记 AI 代码 | PR 被拒绝，要求补标记/重写 |
| 未经审核提交 AI 代码 | PR 拒绝，要求人工审核后重提 |
| 引入许可证冲突代码 | 立即回滚，清理历史，必要时法律咨询 |
| 泄露机密信息 | 立即撤销、轮换密钥、安全审计 |

---

## 例外与豁免

- 仅文档/注释/格式化的 AI 生成：可简化审核
- 纯重命名/格式化的 AI 辅助：可简化审核
- 紧急热修复：经维护者口头确认可先合并，事后补审核
