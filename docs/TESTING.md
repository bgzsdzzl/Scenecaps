# 测试要求

本文档规定 Scenecaps 项目的测试层级、必测配置、验证标准与回归要求。

测试的目的是确认改动在实际使用条件下行为正确，而非仅为满足形式。任何改动都应对其影响范围完成相应的验证。

---

## 一、总则

- 改动应完成与其影响范围相适应的验证；
- 无法编写自动化测试的场景，应说明所采用的其他验证方式；
- 不得声称未实际执行的测试已通过；
- 修复缺陷时，应尽可能验证修改前后的行为差异。

---

## 二、测试层级

| 层级 | 范围 | 手段 |
| --- | --- | --- |
| 单元测试 | 独立函数与类型 | 自动化测试框架（可逐步引入） |
| 集成测试 | 模块之间的交互 | 编辑器自动化测试 |
| 端到端测试 | 完整工作流 | 手动验证与自动化回归 |
| 回归测试 | 核心功能 | 每次发布前执行 |

---

## 三、必测配置矩阵

所有 Pull Request 至少需要在下列配置下完成编译与基本验证：

| 目标 | Editor Development | Game Development | Game Shipping |
| --- | --- | --- | --- |
| Runtime 模块 | 必须 | 必须 | 必须 |
| Editor 模块 | 必须 | 不适用 | 不适用 |
| Niagara 启用 | 必须 | 必须 | 必须 |
| Niagara 禁用 | 必须 | 必须 | 必须 |
| World Partition | 必须 | 必须 | 必须 |

Game 目标不得依赖 Editor 模块。若改动涉及编辑器专用代码，应确认其在 Game 目标中被正确排除。

Niagara 集成默认启用，可通过构建环境变量 `SCENECAPS_WITH_NIAGARA=0` 关闭。验证禁用配置时，需在设置该变量的环境下重新生成工程文件并编译。

## 四、功能测试清单

以下清单用于核心功能的回归验证。改动未直接涉及的项可抽测，涉及项必须覆盖。

| 运行时切换 | 变换、可见性、材质实时更新 |

| 运行时增删改实例 | 实时生效 |

### 4. 程序化生成

| 测试项 | 预期结果 |

## 五、自动化与静态分析

### 1. 持续集成实际执行的检查

持续集成在每次改动时运行以下静态检查。这些检查不执行 Unreal 编译，也不产出可用构建：

| 检查 | 内容 |
| --- | --- |
| Build Validation | 校验 `.uplugin` 与 `Source/` 的模块一致性、`Build.cs` 依赖声明与公开导出宏 |
| Include Check | 校验所有头文件引用可在引擎或项目头文件中解析 |
| Code Quality | Markdown 格式与文档相对链接 |
| Security | 密钥扫描与依赖审查 |
| Project Structure | 基于 `.uplugin` 的结构一致性 |

因此，必测配置矩阵中的编译验证无法由持续集成替代，必须在本地完成。

### 2. 本地编译验证

贡献者应在本地对矩阵中列出的配置完成编译，至少覆盖受改动影响的配置。提交前请确认：

- [ ] 受影响的 Runtime 与 Editor 配置均可编译；
- [ ] Game 目标不依赖 Editor 模块；
- [ ] 无新增编译警告。

### 3. 静态分析

- 编译警告视为错误；
- 可选接入额外的静态检查工具。

---

## 六、内存检查

- 编辑器退出时对象计数应回归基线，无持续增长；
- 无对象之间的引用循环导致无法回收；
- 运行时创建的对象在不再使用后应被正确释放。

必要时可使用引擎的对象列表与引用查询命令进行排查。

---

## 七、性能基准

| 场景 | 目标 | 通过标准 |
| --- | --- | --- |
| 万级实例批量生成 | 低于 2 秒 | 低于 3 秒 |
| 千级对象变体切换 | 低于 100 毫秒 | 低于 200 毫秒 |
| 变体过渡 | 60 帧 | 不低于 55 帧 |
| 千级对象快照记录 | 低于 1 秒 | 低于 2 秒 |
| Actor 池获取与释放 | 低于 1 毫秒 | 低于 2 毫秒 |

基准用于发现明显回退，并非绝对门槛。出现明显超出时，应说明原因或进行优化。

---

## 八、回归测试

发布前应完成以下回归：

- [ ] 空集合的创建、加载与保存；
- [ ] 大规模集合的重建与清空；
- [ ] 多变体之间的切换；
- [ ] 变体过渡的播放、暂停与循环；
- [ ] 批量实例化的生成与销毁；
- [ ] 程序化生成（固定种子）；
- [ ] Data Layer 的分配与切换；
- [ ] 快照的记录与恢复；
- [ ] Actor 池的预热、获取与释放；
- [ ] 修改器的注册、执行与卸载；
- [ ] Niagara 启用与禁用两种状态；
- [ ] 编辑器大纲、视口与详情面板交互；
- [ ] Shipping 配置启动无崩溃。

---

## 九、已知限制

| 现象 | 状态 | 规避方式 |
| --- | --- | --- |
| 大量对象选中时编辑器卡顿 | 已知 | 分批选择或使用搜索 |
| 变体过渡中材质插值闪烁 | 调查中 | 临时禁用材质插值 |
| Niagara 粒子在实例化网格上不渲染 | 引擎限制 | 使用独立对象承载粒子 |

---

## 十、测试环境

- Unreal Engine 5.8 或更高版本；
- 编辑器平台：Windows、macOS 或 Linux；
- 目标平台：Win64、Linux、Mac，与插件清单中声明的受支持平台一致；
- 编译器：Windows 使用 Visual Studio 2022 17.8+，Linux 与 macOS 使用兼容的 Clang 工具链；
- 支持 DirectX 12 或 Vulkan 的显卡（Windows）；
- 内存建议 16 GB 以上。
