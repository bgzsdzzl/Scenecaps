# Scenecaps / 场景胶囊

非破坏性场景集合与关卡组装插件，适用于 Unreal Engine 5.8+。

---

## 功能特性 / Features

- **场景集合 / Scene Collection** - 从模块化条目非破坏性组装场景 / Non-destructive scene assembly from modular entries
- **变体系统 / Variant System** - 稀疏覆盖与运行时插值 / Sparse overrides with runtime interpolation
- **ISM/HISM 批量实例化 / ISM/HISM Batching** - 自动实例化提升性能 / Automatic instancing for performance
- **变体过渡 / Variant Transitions** - 变体间平滑插值过渡 / Smooth interpolation between variants
- **生物群系程序化生成 / Biome Procedural Generation** - 网格、泊松圆盘、噪声聚类、径向分布 / Grid, Poisson Disk, Noise Cluster, Radial
- **Data Layer 集成 / Data Layer Integration** - World Partition 支持 / World Partition support
- **修改器系统 / Modifier System** - 基于阶段的可扩展修改器 / Phase-based extensible modifiers
- **快照记录器 / Snapshot Recorder** - 捕获关卡 Actor 为场景集合 / Capture level actors as scene collection
- **Actor 池 / Actor Pool** - 运行时对象池 / Runtime object pooling

---

## 要求 / Requirements

- Unreal Engine 5.8+
- Niagara（可选 / optional）

## 安装 / Installation

1. 放入 `Plugins/` 目录 / Place in `Plugins/` directory
2. 重新生成项目文件 / Regenerate project files
3. 编译并在编辑器中启用插件 / Build and enable in Editor → Plugins
